命令行选项（CLI options）

命令行选项（CLI Options）是跟在命令名后的修饰符，用于控制命令的具体行为，例如显示详细信息、指定输出格式或设置执行模式。分为短选项和长选项。

短选项指跟在命令后只有单个字母的修饰符，前缀为单个连字符 - 。长选项指跟在命令后由多个字母组成的修饰符，前缀为双连字符 – 。

下面我来介绍Codex常用的命令行选项：

参数 用途 示例
-p、--profile 选择配置方案。你切换 OpenAI / DeepSeek 会用到 codex -p deepseek
-m、--model 指定模型；只选模型，不会自动切换供应商 codex -p deepseek -m deepseek-v4-pro
-C、--cd 指定要处理的项目目录 codex -C ~/projects/demo
-s、--sandbox 设置文件访问范围：read-only、workspace-write、danger-full-access codex -s workspace-write
-a、--ask-for-approval 设置运行命令时何时请求确认：on-request、never codex -a on-request
-c、--config 临时覆盖配置项，可重复指定 codex -c 'model_reasoning_effort="high"'
-i、--image 将图片附在初始请求中 codex -i screenshot.png "分析截图"
--search 启用实时网页搜索 codex --search
-h、--help 查看帮助 codex --help

当然，也有使用频率较少的命令行选项：

参数 用途
--add-dir <路径> 在当前工作目录外，额外允许 Codex 写入指定目录；可重复使用
--no-alt-screen 关闭终端备用屏幕模式
--oss 使用本地模型；通常配合 --local-provider
--local-provider lmstudio 或 --local-provider ollama 指定本地模型服务，仅与 --oss 搭配
--enable <功能> 本次运行启用某个功能开关；可重复使用
--disable <功能> 本次运行关闭某个功能开关；可重复使用
--strict-config 配置中有当前版本不认识的字段时，直接报错
--remote <地址> 连接远程 Codex app-server
--remote-auth-token-env <环境变量名> 从环境变量读取连接远程服务所需的认证令牌；需配合 --remote
--dangerously-bypass-hook-trust 本次运行时跳过对已启用 hook 的持久信任检查

上面列的是交互模式的全局参数。像codex exec、codex review等子命令还有各自专用的参数；例如codex exec --help会显示exec的参数。官方文档也将这些分开列出。

子命令（subcommands）

子命令是命令行工具的一种结构化设计方式，用于将复杂的操作分解为逻辑清晰的模块。

例如，Git、Go、Docker、pip 等工具都使用子命令来区分不同功能。每个子命令可以独立解析参数和选项，允许用户通过类似git commit或pip install的方式调用特定功能。

下面我来介绍Codex常用的子命令：

子命令 用途
codex exec（别名：codex e） 在终端非交互运行 Codex，适合一次性任务、脚本和 CI。例：codex exec "解释项目结构"
codex resume 恢复之前的交互会话。例：codex resume --last
codex review 非交互地检查未提交改动、指定分支差异或某个提交。
codex login / codex logout 登录或移除本地保存的认证信息。
codex mcp 管理 MCP 服务，例如查看、添加、移除或认证服务。
codex plugin 从已配置的插件市场安装、列出或移除插件。
codex plugin marketplace 添加、列出、更新或移除插件市场。
codex doctor 生成诊断信息，用于排查安装、配置、认证、终端或运行环境问题。

当然，也有使用频率较少的子命令：

子命令 用途
codex fork 从已有会话分出一个新会话，保留原会话内容。
codex archive 归档指定会话。
codex unarchive 恢复已归档的会话。
codex delete 永久删除指定会话。
codex cloud（别名：codex cloud-tasks） 在终端浏览或执行 Codex 云端任务。
codex apply（别名：codex a） 将 Codex 云端会话生成的最新差异应用到本地工作区。

以下用于设置和维护：

子命令 用途
codex features 查看功能开关，并启用或关闭部分功能。
codex completion 为 Bash、Zsh、Fish 或 PowerShell 生成命令补全脚本。
codex update 检查或安装 CLI 更新；是否支持自更新取决于安装版本。
codex app 从终端启动 ChatGPT 桌面应用；受操作系统和应用安装状态影响。

我们一般较少使用开发、调试和策略工具：

子命令 用途
codex app-server 启动 Codex app server，主要用于本地开发、调试或协议集成。
codex remote-control 启动或管理本地 app server 的远程控制，也可生成临时配对码。常见子命令包括 start、stop、pair。
codex sandbox 在 Codex 提供的 macOS、Linux 或 Windows 沙箱中运行命令。
codex execpolicy 测试执行策略规则，查看某条命令会被允许、要求确认还是阻止。
codex debug models 输出 Codex 当前识别的模型目录信息。
codex debug prompt-input 以 JSON 查看传给模型的提示输入内容。
codex debug app-server send-message-v2 通过内置测试客户端向 app server 发送一条消息，主要用于调试。

官方参考页把app-server、remote-control和部分debug命令标为实验性或开发用途；命令成熟度可能随版本变化。

斜杠命令（slash commands）

斜杠命令是 Codex、Hermes 等 AI 开发环境中的核心功能，通过在交互式会话或 CLI 中输入 /命令名，可以快速执行复杂操作或重复性任务，而无需每次手动输入完整提示或指令。

在 Codex CLI 的交互界面里输入/，会弹出斜杠命令菜单；继续输入名称可以筛选。运行中的任务还没结束时，可以输入斜杠命令后按Tab，让它在当前任务完成后执行。

下面我来介绍Codex常用的斜杠命令：

命令 用途
/model 选择当前会话使用的模型；可选推理强度时也能调整。切模型不一定等于切供应商。
/fast 开启或关闭快速服务等级；只有当前模型支持时才出现。
/reasoning 调整当前模型的推理强度。
/personality 调整 Codex 的表达风格；模型不支持时可能不显示。
/plan 进入计划模式；可直接附带任务，例如 /plan 规划迁移步骤。
/goal 设置或查看持续目标；支持 edit、pause、resume、clear。
/permissions 修改当前会话的权限与审批模式。
/experimental 查看或切换实验功能；有些更改需要重启。

以下斜杠命令用于查看信息、检查代码与工具：

命令 用途
/status 查看当前模型、会话、权限和上下文使用情况。
/usage 查看账户用量或速率限制信息；可用内容取决于账户和环境。
/debug-config 检查配置来源、配置覆盖和策略要求。
/diff 查看当前 Git 改动，包括尚未跟踪的文件。
/review 让 Codex 检查工作区改动或代码差异。
/mcp 查看已配置的 MCP 服务和工具；可加 verbose 查看更多服务细节。
/hooks 查看和管理生命周期 hooks；非托管的 hooks 可进行信任、停用或重新启用操作。
/skills 浏览并选择要用于当前任务的 Skill。
/apps 浏览可用的连接器，并将所选 app 加入提示。
/plugins 浏览、安装或管理插件及其启用状态。
/ide 将可用的 IDE 文件、选区等上下文加入下一条请求。
/mention 在对话中附加指定文件或文件夹。

以下斜杠命令用于会话与上下文：

命令 用途
/new 在当前 CLI 中开启新对话。
/clear 清空界面并开始新对话；可加标题，例如 /clear 修复测试。
/resume 从会话列表恢复以前的对话。
/fork 从当前对话分出一个新会话，保留原会话。
/side、/btw 开启临时旁支对话，不打断主对话。
/compact 压缩当前对话上下文，保留重点以释放空间。
/rename 给当前会话改名。
/archive 归档当前会话并退出；之后仍可恢复。
/delete 永久删除当前会话及其派生会话；删除前会要求确认。
/copy 复制 Codex 最近一条已完成的回复。
/exit、/quit 退出 CLI。
/app 在 macOS 或 Windows 上将当前会话转到 ChatGPT 桌面应用；条件不满足时不可用。

以下斜杠命令用于输入、界面与终端：

命令 用途
/vim 开启或关闭输入框的 Vim 编辑模式。
/keymap 查看或修改 TUI 键位绑定。
/raw 开启或关闭原始滚动输出模式，方便选取和复制终端内容。
/statusline 设置终端底部状态栏显示哪些信息。
/title 设置终端窗口或标签页标题包含的信息。
/theme 选择终端语法高亮主题。
/ps 查看后台终端及其最近输出。
/stop 停止当前会话启动的所有后台终端。
/pets、/pet 选择或隐藏终端里的宠物。
/init 在当前目录生成 AGENTS.md 指令文件的初始模板。

以下斜杠命令用于账户、支持与迁移：

命令 用途
/logout 退出 Codex 账户。
/feedback 打开反馈流程，可选择附带日志或诊断信息。
/import 导入支持的 Claude Code 或 Cursor 配置、项目文件和会话。

以下斜杠命令用于特定系统或审批场景：

命令 用途
/approve 自动审查拒绝某项操作后，批准重试一次；仅适用于相关审查流程。
/setup-default-sandbox 在 Windows 上配置增强沙箱；仅在特定沙箱状态下出现。
/sandbox-add-read-dir 在 Windows CLI 中为沙箱增加目录读取权限。
/agent、/subagents 切换到某个子代理会话；有子代理会话时才有用。

快捷键和交互输入语法

这些符号和快捷键要在 Codex CLI 的对话输入框里使用，不是在普通终端提示符里使用。

1.输入符号

输入 作用 示例
@ 搜索并把工作区中的文件或路径加入提示，方便指定 Codex 要看的内容 @src/main.py 检查这个文件
! 在 Codex 输入框中运行本地 shell 命令，遵循当前审批和沙箱设置 !git status

2.常用快捷键

按键 作用
↑ / ↓ 浏览、恢复输入草稿历史
Ctrl+R 搜索提示词历史；选中后按 Enter 使用，按 Esc 取消
Ctrl+O 复制 Codex 最近一条已完成的回复，也可以输入 /copy
Tab Codex 正在工作时，将后续提示、斜杠命令或 shell 命令排队，等当前任务结束后执行
Enter Codex 正在工作时，把补充指令插入当前任务
输入框为空时连按两次 Esc 编辑上一条用户消息，并从那里分出一个新会话
Ctrl+L 仅清除终端画面，当前对话仍保留
Ctrl+C 退出 CLI；也可以输入 /exit
