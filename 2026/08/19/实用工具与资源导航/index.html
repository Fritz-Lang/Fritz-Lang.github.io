实用工具与资源导航

发表于2026-08-19|更新于2026-08-24|工具
|浏览量:

🛠️ 开发工具

  • VS Code —— 最流行的代码编辑器，插件生态强大
    • 编程必备插件：
      • Code Runner —— 支持快速运行和调试代码
      • GitGraph —— 可视化 Git 分支和提交历史
    • Python插件：
      • Pylance —— 提供高性能的语言支持
      • autopep8 —— 将Python代码自动格式化为PEP8风格
      • Ruff —— 高性能 Python 代码检查器和格式化工具
    • Markdown插件：
      • Markdown All in one —— 提升 Markdown 写作效率
      • Markdown Preview Github Styling —— Markdown 预览功能与GitHub的显示风格保持一致
    • 远程连接插件：
      • Remote - SSH —— 通过 SSH 协议连接远程服务器并在本地开发环境中操作远程文件系统
  • Git —— 目前世界上最先进的分布式版本控制系统
  • uv —— 提供更快的性能，同时保持简单直观的用户体验
    • uv教程 —— 从安装到使用
  • Homebrew —— macOS 上的一个强大包管理工具
  • Node.js —— 一个开源JavaScript 运行时环境，它让开发人员能够创建服务器、 Web 应用、命令行工具和脚本

📚 技术文档

  • 菜鸟教程 —— 中文编程入门教程
    • Markdown 教程 —— Markdown 是一种轻量级标记语言，可以使用易读易写的纯文本格式编写文档
  • DevDocs —— 聚合多种技术文档的查询工具
  • 免费编程书籍 —— GitHub 上的免费编程书籍合集
  • Z-library —— 世界上最大的电子图书馆，每个人都可以自由访问知识与文化
  • Hexo —— 快速、简洁且高效的博客框架
    • Stellar —— 一个内置文档系统的简约商务风 Hexo 主题
    • Butterfly —— Hexo 的简单卡片式 UI 设计主题

💻 算法教程

  • 吴恩达机器学习 —— 入门机器学习的经典课程

🧰 在线工具

  • EPUB 在线编辑器 —— 在浏览器中直接编辑 EPUB 电子书，提供所见即所得的编辑体验

🌐 优质技术社区

  • GitHub —— 全球最大的代码托管平台
  • Stack Overflow —— 程序员问答社区
  • V2EX —— 中文技术创意社区
