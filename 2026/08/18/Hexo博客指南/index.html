Hexo博客指南

发表于2026-08-18|更新于2026-08-24|工具
|浏览量:

1. Hexo项目结构

Blog
├── _config.yml # 网站的主配置文件
├── package.json # Node.js 项目依赖管理文件
├── public/ # 生成的静态页面（执行 hexo g 后出现）
├── scaffolds/ # 文章模板文件夹
├── source/ # 资源文件夹，存放所有内容源文件
│ └── _posts/ # 文章文件夹，存放已发布的 .md 文章
└── themes/ # 主题文件夹

  • _config.yml：网站的核心配置文件。可以在这里配置网站的大部分参数，例如站点名称、描述、URL、部署设置等。
  • scaffolds/：模板文件夹。当使用 hexo new 命令新建文章或页面时，Hexo 会根据此文件夹中的模板（如 post.md）来生成文件。
  • source/：资源文件夹。这是存放所有内容的地方。包含_posts文章，以及一些独立界面如：分类、标签或关于。
  • themes/：主题文件夹。用于存放网站的主题，Hexo 会根据所选的主题来生成静态页面。

此博客采用 Butterfly 主题，并且部署在 Github Pages，通过 npm 安装后会多出一些必要文件：

Blog
├── … # hexo配置文件
├── _config.butterfly.yml # butterfly主题的配置文件
├── .deploy_git # hexo-deployer-git 插件
├── .github # 存放 GitHub Actions 工作流文件
└── package-lock.json # npm 自动生成的依赖版本锁定文件

2. 基本操作

2.1 新建文章

hexo new post “我的第一篇文章”

生成的文件在 source/_posts/ 我的第一篇文章.md。

2.2 文章头部 Front-matter

title: 我的第一篇文章
date: 2025-08-16 15:00:00
categories: 学习
tags: [Hexo, 教程]
top: true # 置顶
abbrlink: 1234 # 固定链接（需插件）
password: 123 # 密码保护

3. 分类 / 标签 / 归档

3.1 文章中的分类与标签

categories: 技术
tags: [Hexo, Node.js]

  • 分类：有层级关系（categories: [技术, 前端]）
  • 标签：自由标签，无层级。

3.2 分类、标签、归档页面

Hexo 不会自动生成 /categories/、/tags/、/archives/ 页面，需要手动新建：

hexo new page categories
hexo new page tags
hexo new page archives

修改生成的 index.md：

-–
title: 分类
type: categories
-–

-–
title: 标签
type: tags
-–

-–
title: 归档
type: archives
-–

这样访问 /categories/ 就能显示分类索引。

4. 独立页面

如果你在菜单里配置了页面入口，就需要在 source/ 下新建对应文件夹：

例如：

menu:
  主页: / || fas fa-home
  生活 || fas fa-list:
    相册: /photos/ || fa fa-camera-retro
    音乐: /music/ || fa fa-music

则需要在 source 目录下新建：photos/index.md 和 music/index.md

5. 部署博客

5.1 常用命令

hexo clean # 清理缓存和 public/
hexo g # 生成静态文件
hexo s # 本地启动预览
hexo d # 部署到远程

5.2 Git 部署

在终端里安装部署插件：

npm install hexo-deployer-git –save

在 config.yml 里配置：

deploy:
  type: git
  repo: git@github.com:用户名/用户名.github.io.git
  branch: master

并执行：

hexo clean && hexo g && hexo d

6. 常见问题与技巧

  • 文章目录（TOC）：主题支持自动生成目录，需在 _config.yml 开启。
  • 置顶文章：在 Front-matter 加 top: true。
  • 加密文章：安装 hexo-blog-encrypt，Front-matter 写 password: xxx。
  • 多作者协作：推荐用 Git 管理 Hexo 源码（不是 public/），每人写完文章 push，再统一部署。
  • 主题优化：可以修改主题的样式文件（如 Butterfly 的 _layout/*.styl），实现自定义公告栏、背景、特效等。

7. 推荐工作流

  • 写文章：

  • hexo new post “标题”

  • 本地预览：

  • hexo s

  • 部署到 GitHub Pages：

  • hexo clean && hexo g && hexo d

8. 总结

Hexo 是一个非常灵活的博客框架，你可以从最基础的写文章开始，逐步扩展分类、标签、搜索、评论、统计等功能。
