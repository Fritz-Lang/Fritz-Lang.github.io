1 为什么想搭这个博客？

撰写本文前，我一直使用备忘录或者网页标签的形式记录一些知识，过于繁琐而且不能很好的将这些知识整合，在了解了博客这一记录形式后，决定搭建一个个人博客，用来记录技术工具、研究项目以及生活琐事。尽管网上有很多现成的平台，但还是倾向于自己搭建一个，有更高的自由度，也能顺便学习一下前端工具链。

这次选择了 Hexo + GitHub 的组合，原因很简单：免费、轻量、纯静态。

2 安装

本项目是基于 Macos 搭建，从 Node.js -> Git -> Github -> Hexo 逐步介绍。

2.1 环境搭建

Hexo 基于 Node.js，搭建过程中还需要使用 npm（Node.js 已带）和 git，因此先搭建本地操作环境，安装 Node.js 和 Git。

2.1.1 Node.js

简单的说 Node.js 就是运行在服务端的 JavaScript。

推荐使用nvm来安装，因为可以在不同项目间切换 Node.js 版本。

1.安装 nvm：在“终端”中运行以下命令：

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

2.并执行下述代码使配置生效：

source ~/.zshrc

3.推荐安装 Node.js的稳定版本，即 LTS 版本。执行以下命令，nvm 会自动下载并安装最新的 LTS 版本：

nvm install --lts

4.安装完成后，执行以下命令切换到 LTS 版本：

nvm use --lts

5.安装完成后输入以下命令来检查是否安装成功：

node -v && npm -v

如果看到类似 v24.18.0 和 11.17.0 的版本号，就说明 Node.js 已成功安装。

2.1.2 Git

Git是目前世界上最先进的分布式版本控制系统。这里只介绍如何安装，Git的具体使用详见Git教程。

在Macos上下载Git，第一种方式较为简单，但需要下载一个巨大的XCode。而第二种方式是先安装包管理器Homebrew，然后通过Homebrew安装Git。这里更推荐第二种，下面我来介绍下：

第一步：安装 Homebrew

方法一：官方脚本安装

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

方法二：Homebrew 最新的GitHub发布页中下载.pkg文件

第二步：使用 Homebrew 安装 Git

1.在“终端”中执行以下命令：

brew install git

2.等待命令执行完毕，Homebrew 会自动下载并安装最新版本的 Git。

3.安装完成后输入以下命令来检查是否安装成功：

git --version

如果能看到版本号（如 git version 2.x.x ），就说明 Git 已成功安装。

4.安装好 Git 后，还需要最后一步设置，在命令行输入：

git config --global user.name "Your Name"
git config --global user.email "email@example.com"

注意 git config 命令的 --global 参数，用了这个参数，表示你这台机器上所有的Git仓库都会使用这个配置。
名字和邮箱地址推荐和 GitHub 设置相同。

2.2 Github仓库

GitHub 是一个基于 web 的版本控制和代码管理服务平台，它主要用于计算机代码的存储、管理和跟踪变更。我们使用邮箱注册 GitHub 账户，选择免费账户（Free），并完成邮件验证。

本地 Git 配置好，要连接到远程 Github 库中，分为两个问题：如何连接？远程库如何创建？

第一步：连接到远程库

1.创建 SSH 密匙：

ssh-keygen -t rsa -C "GitHub 邮箱"

2.添加密匙：

进入 ~:\Usrs\用户名\.ssh 文件夹，由于默认隐藏，按下 command + shift + . 显示，双击打开公钥 id_rsa.pub 文件并复制里面的内容。

登陆 GitHub ，进入 Settings 页面，选择左边栏的 SSH and GPG keys，点击 New SSH key。

Title 随便取个名字，粘贴复制的 id_rsa.pub 内容到 Key 中，点击 Add SSH key 完成添加。

3.验证连接：

在终端中输入 ssh -T git@github.com 出现 “Are you sure……”，输入 yes 回车确认。

显示 “Hi xxx! You've successfully……” 即连接成功。

第二步：创建 Github 仓库

1.GitHub 主页右上角加号 -> New repository：。

2.Repository name 中输入 用户名.github.io。

3.勾选 “Initialize this repository with a README”，此外，Description 可以选填。

4.填好后点击 Create repository 创建。

2.3 安装Hexo

Hexo 是一个快速、简洁且高效的博客框架，使用 Markdown 或其他渲染引擎解析文章，并在几秒内生成静态网页。

新建一个文件夹用来存放 Hexo 的程序文件，如 Blog ，从终端使用 cd + Blog文件夹的绝对路径 进入这个文件夹。

1.使用 npm 一键安装 Hexo 博客程序：

npm install -g hexo-cli

安装完成后如下图:

2.Hexo 初始化并安装所需组件：

hexo init      # 初始化
npm install    # 安装组件

3.完成后依次输入下面命令，启动本地服务器进行预览：

hexo g   # 生成页面
hexo s   # 启动预览

访问 http://localhost:4000，若出现 Hexo 默认页面，则本地博客安装成功。

4.部署 Hexo 到 GitHub ，使其能够在网络上访问：

安装 hexo-deployer-git：

npm install hexo-deployer-git --save

然后修改 _config.yml 文件末尾的 Deployment 部分，修改成如下：

deploy:
  type: git
  repository: git@github.com:用户名/用户名.github.io.git
  branch: main

完成后运行 hexo d 将网站上传部署到 GitHub Pages。

完成！这时访问我们的 GitHub 域名 https://用户名.github.io 就可以看到 Hexo 网站了。

3 使用方法

使用vscode打开hexo所在目录，启动终端。

1.创建博文：

hexo new "My New Post"

然后 source 文件夹中会出现一个 My New Post.md 文件，就可以使用 Markdown 编辑器在该文件中撰写文章了。

也可以不使用命令自己创建 .md 文件，只需在文件开头手动加入如下格式 Front-matter 即可

2.文章渲染并部署:

hexo g   # 生成页面
hexo d   # 部署发布
#或者合并
hexo g -d

3.本地预览:

hexo s

4.清除缓存和已生成的静态文件:

hexo clean

5.帮助

hexo help
